BE2 담당 영역. 역할 문서와 docs/contracts.md를 기준으로 구현합니다. 공통 계약 변경은 담당자 리뷰가 필요합니다.

`availability.ts`는 상담 가능 시간의 순수 입력 검증만 담당합니다. DB·HTTP에 연결하지 않으며 업무 라우트를 열지 않습니다.

형식 검증은 `staff_id` UUID, 달력 날짜(`YYYY-MM-DD`), 오프셋 없는 하루 시각, `Z`로 끝나는 UTC 절대 시각을 구분합니다. 같은 날 시각 구간과 UTC 절대 구간은 종료가 시작보다 뒤여야 합니다. 같은 날 검사는 자정을 넘는 구간을 표현하지 않으며, 자정 넘김을 금지하는 정책이 아닙니다.

`interval.ts`는 `availability.ts`의 비교 함수만 사용해 두 구간의 끝점 순서를 13가지 관계로 반환합니다. 하루 시각 관계는 두 구간이 같은 하루라는 전제에서만 계산합니다. `meets`는 `overlaps`와 다르고, 이 관계는 예약 충돌이나 경계 포함 정책이 아닙니다.

요일 번호, 시간대 저장, 예외 시간의 종류와 우선순위, 맞닿은 구간을 중복으로 볼지는 합의 전입니다. 자정을 넘는 하루 시각은 나누거나 다른 시간대로 바꾸지 않습니다.
