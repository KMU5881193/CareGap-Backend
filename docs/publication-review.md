# 공개 전 점검 — 2026-10-29

- fetch로 원격 브랜치·태그와 로컬 수정 상태를 다시 확인했습니다. 기존 main과 BE3 작업을 초기화하거나 덮어쓰지 않았습니다.
- 전체 도달 가능한 커밋의 파일 객체를 검사했습니다. 협업 문서 추가 전 백엔드 36개·프론트 32개 역사적 blob을 확인했습니다. 이후 추가 문서는 별도 diff 검토했습니다.
- 추적된 비밀 설정 경로는 .env.example과 save-exact 설정만 있는 .npmrc입니다. 실제 .env, 개인키, API 토큰 파일은 발견되지 않았습니다.
- 알려진 토큰/개인키 패턴, 내부 네트워크 URL, 이메일 패턴과 설정·문서·합성 fixture를 검사했습니다. API 키·실제 접근 토큰·운영 DB 자격증명·실제 상담 자료·비공개 서버 주소는 확인되지 않았습니다. 패턴 검사가 모든 종류의 비밀을 완전 탐지한다는 뜻은 아닙니다.
- Compose의 local-only는 공개 가능한 로컬 개발용 예시 비밀번호입니다. 운영/공용 DB에 사용하지 않습니다. DB 주소는 loopback 예시입니다.
- 프론트 잠금 파일의 이메일 검출 1건은 glob 패키지가 공개 배포한 deprecated 안내문의 유지관리자 연락처였습니다. 팀 개인정보나 비밀정보가 아닙니다.
- 커밋 작성자 실명·학교 이메일은 Git 메타데이터에 있습니다. 사용자가 이를 알림받은 뒤 공개를 명시 허용했습니다. 과거 기록을 지우지 않았으며 공개하면 이 정보도 보입니다.
- 기존 프로젝트 코드 이식으로 확인된 파일은 없습니다. 역할 참고 문서의 업로드 원본 SHA-256 대조와 파일별 분류는 initialization-audit.md에 있습니다.
- 민감정보 발견 시 Public 전환을 중단하고 보고합니다. 최신 파일 삭제만으로 과거 기록이 지워지지 않습니다. 자격증명 폐기/교체 및 필요한 기록 정리는 별도 승인 대상입니다.
- 공개 및 병합은 사용자 승인 범위에서 CI 통과 후 수행합니다. 실제 상태와 PR/CI 링크는 최종 보고를 기준으로 확인하세요. Fork/PR 협업 절차는 CONTRIBUTING.md를 참고하세요.
